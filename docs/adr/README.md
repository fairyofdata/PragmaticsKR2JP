# 설계 결정 기록 (ADR)

ADR(Architecture Decision Record) = 중요한 설계 결정 하나를 "맥락 → 결정 → 버린 대안 → 결과" 순서로 짧게 적은 문서.
결정을 뒤집을 때는 기존 ADR을 지우지 않고 상태를 "대체됨"으로 바꾸고 새 ADR을 쓴다.

**기록 규칙 (2026-09-30~):** 주요 작업 변동사항은 따로 지시가 없어도 작업한 턴 안에서 ADR로 남긴다.
새 기능, 설계 결정과 버린 대안, 버전 변경(유형표·프롬프트·스키마), 외부 리뷰 반영, 실험이 바꾼 판단, 발견한 버그와 원인이 대상이다.
판단이 들어가지 않은 변경(오타, 문구)은 커밋 메시지로 충분하다.
