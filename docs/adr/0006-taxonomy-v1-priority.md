# 0006. 유형표 v1: 더 구체적인 유형을 우선

- 상태: 채택 (2026-09-20)

## 맥락
유형표의 순서는 우선순위다(두 유형에 걸치면 위쪽). v0 은 WORD_CHOICE 가 COLLOCATION 보다 위였다.
p0 실험에서 모델은 `薬を食べる`를 WORD_CHOICE 로 태깅했다 — 모델 잘못이 아니라 유형표 규칙을 그대로 따른 결과였다.
또 반각 `!?` 를 표기 오류로 지적해 무오류 답에 태그가 붙었다.

## 결정
- v1: COLLOCATION 을 WORD_CHOICE 위로. 원칙은 "더 구체적인 유형이 위".
- COLLOCATION 경계 문구 추가: 문제가 짝이 되는 말과의 조합에 있으면 여기.
- ORTHOGRAPHY 경계 문구 추가: 전각/반각 차이는 오류가 아니다 (프롬프트로는 안 지켜져서 코드 필터도 추가, 0002 참고).
- 유형 구성(13개)은 v0 과 같다. 순서 변경도 태깅 결과를 바꾸므로 버전을 올렸다.

## 결과
- v0 과 v1 기록은 섞어 집계하지 않는다 (`stats.filter_records`).
