# 0012. 버전 필터는 측정 도구만 본다 (스키마 제외)

- 상태: 채택 (2026-09-30). ADR 0009 의 결정 2(버전 필터)를 **일부 대체**.

## 맥락
ADR 0009 에서 외부 리뷰를 반영해 "유형표·프롬프트·스키마·모델이 모두 현재와 같은 기록만" 기본 집계하도록 했다.
그런데 스키마 변경은 대부분 **필드 추가**다 (s2→s3 입력 방식, s3→s4 겨냥 연습). 측정 결과에는 영향이 없다.
이대로면 사용자가 몇 주 동안 실제 기록을 쌓은 뒤 필드를 하나 추가하는 순간, 그 기록이 전부 기본 화면에서 사라지고
주간 추이(ADR 0011)도 끊긴다. 개인 코퍼스를 쌓기 시작하는 시점이라 지금 정해야 했다.

## 결정 (사용자 선택)
- 기본 필터 = **측정 도구의 버전**: 유형표 · 채점 프롬프트 · 모델. 이 셋이 다르면 같은 답도 다르게 태깅될 수 있다.
- 스키마(저장 형식)는 필터에서 뺀다. 저장 코드는 옛 기록의 빠진 필드를 기본값으로 읽는다.
- 토글("이전 버전 기록도 포함")과 섞인 구성 경고는 그대로. 구성 표시는 (채점 프롬프트, 모델)로 바꿨다.
- 출제 프롬프트(과제 만들기, 겨냥 과제)는 측정 도구가 아니므로 버전에 넣지 않는다. 대신 기록에 과제 본문과 입력 방식이 남는다.

## 결과
- `stats.VERSION_KEYS = ("taxonomy_version", "prompt_version", "model")`. 테스트: 스키마만 다른 기록은 포함, 유형표가 다르면 여전히 제외.
- 앞으로 스키마를 올려도 기록이 사라지지 않는다. **스키마 변경이 필드 의미를 바꾸는 경우**(예: 같은 필드의 뜻이 달라짐)에는
  그때 새 ADR 로 "호환 안 되는 스키마 버전"을 필터에 다시 넣는다.
