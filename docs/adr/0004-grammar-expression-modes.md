# 0004. 문법 모드 / 표현 모드 분리

- 상태: 채택 (2026-09-20)

## 맥락
유형표를 언어학적으로 검수하니 한국어 화자에게 중요한 영역(문체·장면 적합성, 태·수수·자타동사, 담화·지시어)이 빠져 있었다.
전부 넣으면 13개가 되어 한 번에 고를 선택지가 많아지고 재현성이 떨어진다. 사용자 제안: 화용 쪽이냐 통사 쪽이냐를 모드로 골라,
반대쪽을 조금 놓치더라도 한쪽의 재현성을 높이자.

## 결정
- **문법 모드**(형태·통사: 정확성): 조사, 활용, 시제·상, 태·수수·자타동사, 접속.
- **표현 모드**(어휘·화용: 적절성): 경어·정중체, 문체·장면 적합성, 문말, 연어·관용, 어휘 선택, 문장 구조·담화.
- 공통: 표기·오타·변환 실수, 기타.
- 어휘는 엄밀히는 통사와 화용 사이지만, 사용자의 문제(ほぼ/ほとんど/大体)가 쓰임새 문제라 표현 모드에 둔다.
- 모드 밖 오류도 `OUT_OF_MODE` 로 태깅한다(검증 E 가 모드와 상관없이 동작하도록). 집계에서는 뺀다.
- "한국어 직역 간섭"은 유형이 아니라 별도 플래그 (원인과 현상은 다른 축).
- 과제에 매체(메일/채팅/구두)와 관계를 붙이고 그 장면 기준으로 판정.

## 결과
- 실험 (p1): 문법 모드는 guide·vote 모두 심은 오류 위치를 모두 잡았다(1.00). 표현 모드는 plain 0.93 / guide 0.81 / vote 0.74 — 문법 모드보다 낮고, 선행 연구의 예상과 같은 방향.
- 경계에서 판단이 갈리는 문항이 있다(G2 `担当するので`: 시제·상으로도, ことになる 표현 문제로도 볼 수 있음).
