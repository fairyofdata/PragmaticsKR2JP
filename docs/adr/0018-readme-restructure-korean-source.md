# 0018. README 재구성: 한국어 원본, 상태·측정 도구를 앞에, 실험 상세는 분리

- 상태: 채택 (2026-10-26)

## 맥락
사용자가 README 갱신 아이디어를 요청했고, 이어서 다른 저장소 5개(프로필 `fairyofdata`, RAGSTT4Lyrics, PortfolioOpt4ESG, PhonemeJP2KR, Neutralize4KRJP)까지 포함해 **모두 반영**하기로 했다. 이 저장소 README 에서 찾은 문제:
- 사실과 다른 곳: 실험 절의 "스키마 s2"(실제 s4), 비용 표의 채점 1번 $0.02(p1 기준. p2 는 약 $0.04, 같은 README 의 고쳐 쓰기 항목과도 어긋남), 영문판 "Result 2"(Result 1 은 한국어판에만), 폰 스크린샷 아래로 밀려난 시연 예시 안내, 구조 목록에서 빠진 `tools/`·`tests/`·CI·`HANDOFF.md`.
- 구조: 설계 원칙 6개 절(약 100줄)을 지나야 실행법이 나왔다. 실험 상세 때문에 한국어판만 220줄로 길었고, 영·일판과 내용이 달랐다.
- 방향: 도입부가 조사 오류 중심이라 최초 기획(화용, ADR 0015)이 약하게 드러났고, 실사용 0건·실제 폰 미확인 같은 상태가 README 에 없었다.

## 결정
1. **원본 언어는 한국어, GitHub 첫 화면은 영어.** 원본은 작성자가 뉘앙스까지 확인할 수 있는 언어여야 한다. 각 README 맨 위 HTML 주석에 원본과 동기화 날짜를 적는다 (독자에게는 보이지 않음). 6개 저장소에 같은 규칙을 적용했다. 언어 전환 줄 형식도 통일했다.
2. **순서**: 요약 3줄 → 빠른 시작 → 흐름도 → 왜 만들었나 → 지금 상태 → 설계 원칙 → 실험 요약 → 비용 → 개인정보와 운영 → 구조 → 다음 단계.
3. **흐름도**(mermaid): 검증 A~E2 가 한 바퀴의 어디서 작동하는지 보이게 한다.
4. **"지금 상태" 표와 "현재 측정 도구" 표**를 둔다. 실사용 0건, 실제 폰 미확인, p2 본 실험 보류, 아직 없는 기능(실제 일본어 입력, 상대가 바뀌면, 말하기)을 숨기지 않는다. 측정 도구 표는 버전 필터(ADR 0012)가 무엇을 기준으로 묶는지를 보여준다.
5. **"왜 만들었나"를 최초 기획에 맞춘다**: "교사처럼 무엇이 적절한지 알려주는 사람이 없다"를 먼저, "틀린 것을 틀린 그대로"를 그 다음에.
6. **실험 상세는 `experiments/README.md`(한국어)로 옮긴다.** README 에는 p1 표 하나와 결론 5줄만. 세 언어판이 같은 내용을 갖게 된다.
7. **비용 표는 p1 / p2 두 열**로. p2 실측 1건($0.04)을 그대로 적고, 실험 비용은 예상치로 표시한다. 유료 재실행 없이 고칠 수 있는 범위다.
8. **개인정보와 운영 절**: 기록은 로컬 JSONL, 밖으로 나가는 것은 LLM API 로 보내는 문장뿐, 네트워크에 여는 길은 `tools.run_mobile` 하나, 배포 없음, 개인정보 게이트 연계 예정.

## 버린 대안
- **영어 원본**: 범용적이지만, 작성자가 가장 확인하기 어려운 판이 기준이 된다.
- **프로필만 일본어 첫 화면**: 일본 취업에는 맞지만, 일본 엔지니어·채용 담당자도 영어 README 는 읽는다. 일본어판은 맨 위 링크 한 번이면 닿는다.
- **원본 표시를 독자에게 보이게("한국어판이 원본입니다")**: 영어 독자에게 "이 판은 부차적"이라고 말하는 셈이라 숨은 주석으로 했다.
- **실험 상세를 세 언어로 모두 번역**: 수치를 고칠 때 세 곳을 맞춰야 하는 문제가 다시 생긴다.

## 결과
- 영·일판의 설계 원칙 절은 기존 번역을 그대로 두었다 (내용이 한국어판과 같았다). 한국어판에는 영·일판에만 있던 E2 행과 전각/반각 문장을 넣었다.
- 연습 화면 스크린샷(`practice.png`, 2026-09-20)은 예전 화면이다. 다시 찍는 데 API 비용(약 $0.04)이 들어, 보류한 유료 작업과 함께 한다. 캡션에 촬영일과 그 사실을 적었다.
- 다른 저장소의 변경(제목을 저장소 이름으로, 과장 문구 정리, 한계 절, Neutralize4KRJP 의 LICENSE·CI, RAGSTT4Lyrics 의 라이선스 문구·노트북 이동)은 각 저장소의 커밋과 RAGSTT4Lyrics ADR-0014 에 있다.
