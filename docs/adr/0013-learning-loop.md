# 0013. 학습 순환: 고쳐 쓰기, 약점 겨냥 연습, 표현 참고

- 상태: 채택 (2026-09-30)

## 맥락
도메인 점검(ADR 0010)에서 "지적하고 끝"인 구조가 학습 도구로서 가장 큰 공백이었다.
제2언어 습득에서 교정 피드백의 효과는 학습자가 알아차리고, **스스로 고쳐 쓰고**, **다시 마주치는** 데서 나온다.
동시에 이 앱은 측정 도구이기도 해서, 학습 기능이 측정(빈출 오답·상위 5개·추이)을 오염시키면 안 된다.

## 결정 (모두 사용자 선택)

### 1. 고쳐 쓰기: 무료 확인 + 선택 재채점
- 결과 아래 "교정 가리고 다시 쓰기": 교정과 해설은 가리고 **틀린 자리와 유형만** 표시한다 (정답을 주는 대신 스스로 고치게 하는 방식).
- "확인"은 코드로 한다 (`verify.check_revision`, 언어 무관, 무료). 틀렸던 자리마다:
  고침 / 그대로(안 고침) / 다르게 고침(다른 맞는 표현일 수도, 여전히 틀렸을 수도).
  원래 답과 고쳐 쓴 답의 차이에서 그 자리가 바뀌었는지 보고, 바뀐 곳을 교정 길이만큼 넓혀 교정이 들어 있는지 본다 (`東京→東京に` 같은 삽입 교정 대응).
- "다시 채점"(약 $0.04)을 누르면 3회 채점해서 **고쳐 쓰고도 또 틀린 패턴**을 찾는다 (패턴 키 비교, 유형 이름은 흔들릴 수 있어 제외).
  이것은 실수가 아니라 오개념이라는 강한 신호다.
- 고쳐 쓴 답은 피드백을 본 뒤라 독립적인 시도가 아니다 → `data/revisions.jsonl` 에 따로, **집계에 넣지 않는다**.
  재채점은 같은 id 로 새 줄을 추가 (마지막 줄이 이긴다). 재채점 결과도 `attempts.jsonl` 에 넣지 않는다.
- 요약 탭 "고쳐 쓰기에서 드러난 것": 패턴별 고침/그대로/다르게/또 틀림.

### 2. 약점 겨냥 연습: 넣되 집계와 분리
- 입력 방식 "약점 겨냥 연습": 후보 = 빈출 오답 + '몰랐음'으로 판정한 패턴(한 번뿐이어도).
- 출제 프롬프트는 그 표현을 쓰지 않고는 완성하기 어려운 상황을 만들되, **정답·오류·일본어를 암시하지 않게** 한다.
  실제 출력 확인: `を → に (… 会う)` → "동료에게 회의실 앞에서 만나자고 제안", `ほぼ → ほとんど` → "대부분 통과, 일부 남음 공유". 정답 누설 없음.
- 기록은 `input_mode="targeted"` 와 `target`(겨냥한 패턴). **빈출 오답·상위 5개·추이에서 뺀다** — 일부러 약점을 유도하므로 넣으면 그 유형 비율이 인위적으로 올라간다.
- 대신 결과를 따로: 또 틀림 / 맞게 씀 / 그 표현을 쓰지 않음(피해 간 것은 맞게 쓴 것으로 치지 않는다).
  '맞게 씀'은 교정 쪽 기본형이 걸리는 말 바로 앞에 **연속으로** 나와야 인정한다 (`に` + `会う`).

### 3. 표현 참고
- 최소 교정에서는 넘기고 자연스러운 문장에서만 바꾼 곳(`その→あの`, ADR 0002 의 남은 끌려가기 경로)을
  확정 교정문과 자연스러운 문장의 차이로 하이라이트해서 "표현 참고"로만 보여준다. **집계 제외.**
- 자연스러운 문장이 사실상 다시 쓴 글이면(글자 유사도 0.6 미만) 하이라이트를 생략한다.
  단어 개수로 판단하려 했으나, 짝을 못 지으면 한 덩어리로 묶여서 다시 쓴 글도 "2군데"로 세어졌다 → 글자 유사도로 바꿨다.

## 구현 중 발견한 것
- '맞게 씀' 판정이 처음에는 "답 어딘가에 に, 어딘가에 会う" 수준이라, `一緒に … 合って` 같은 답도 맞게 쓴 것으로 판정했다.
  화면 확인 중 발견해서 연속 출현으로 고치고 회귀 테스트를 넣었다.
- 고쳐 쓰기 확인에서, 조사만 고치고 한자(`合って`)는 그대로 둔 답이 조사 태그 "다르게 고침", 표기 태그 "그대로"로 정확히 갈렸다.
  합쳐진 태그(`友達を合って→友達に会って`)는 일부만 고치면 "다르게 고침"이 된다 — 재채점으로 확인하도록 안내한다.

## 한계
- 고쳐 쓰기 확인은 문자열 근처 비교라, 문장을 크게 바꿔 쓰면 "다르게 고침"이 늘어난다 → 재채점으로 확인.
- 겨냥 연습의 '그 표현을 쓰지 않음'은 피해 간 것인지, 다른 맞는 표현을 쓴 것인지 구별하지 않는다.
- 스키마 s4 (`input_mode='targeted'`, `target`, `Revision`). ADR 0012 로 스키마는 집계 필터에 영향이 없다.
