# 0022. 표준 하네스 v2: 지금 상태는 state.md 하나에, CLAUDE.md 에는 쓰지 않는다

- 상태: 채택 (2026-11-16) · 0017 의 인수인계 문서 위치와 SessionStart 훅의 역할을 바꾼다

## 맥락
지금 상태가 두 곳에 있었다. `docs/HANDOFF.md`(지금 멈춘 지점, 답 대기, 미확인)와 `CLAUDE.md` 의 「현재 상태와 다음 할 일」 절이다. 같은 항목(배포 질문, 비용 드는 보류)이 두 곳에 따로 적혀 있었다. 또 CLAUDE.md 는 매 세션 읽히는 규칙 파일인데 진행 상황 때문에 계속 길어졌다. 인수인계 문서를 갱신하는 것도 지시문뿐이었고, 갱신을 확인하는 장치는 없었다.

## 결정
1. 지금 상태는 저장소 루트 `state.md` 하나에 둔다 (git 제외, 0021 과 같은 이유). `CLAUDE.local.md` 의 `@state.md` 로 매 세션 읽힌다.
2. CLAUDE.md 의 「현재 상태와 다음 할 일」 절은 지운다. 그 절의 「완료」 줄은 ADR 색인과 git 이력에 있다. 나머지는 state.md 로 옮겼다.
3. 옛 HANDOFF 의 1·2·4·5절(지금 상태)은 state.md 로, 6~8절(일하는 방식·환경에서 걸린 것·명령)은 CLAUDE.local.md 로 옮겼다. 문구는 그대로다. 원문 전체는 로컬 보관본에 있다.
4. 장치: `/state` 스킬(갱신 절차)과 Stop 훅(커밋했는데 state.md 를 안 고쳤으면 한 번 알림)을 둔다. 둘 다 `.claude/`(git 제외)에 있다. SessionStart 훅 `tools/session_handoff.py` 는 지금의 git 상태만 덧붙인다.

## 결과
- CLAUDE.md 가 짧아졌고, 진행 상황 때문에 바뀌지 않는다.
- 대가: state.md 는 이 PC 에만 있다. 다른 곳(클라우드 세션)에서는 0021 때와 마찬가지로 상태를 이어받지 못한다.
