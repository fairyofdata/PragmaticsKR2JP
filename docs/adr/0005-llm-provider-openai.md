# 0005. LLM 제공자: Gemini → OpenAI

- 상태: 채택 (2026-09-20). 처음 결정(Gemini)을 대체.

## 맥락
처음에는 Gemini 로 정했다(이전 프로젝트 경험, 싸고 빠름, 구조화 출력 지원).
실제로 돌려 보니 무료 등급 `gemini-3.8-flash` 한도가 분당 5회·**하루 20회**라, 호출 180회짜리 실험과 3회 다수결을 돌릴 수 없었다.

## 결정
- 기본 OpenAI. 채점 `gpt-5.6-terra` (입력 $2 / 출력 $12, 100만 토큰당), 출제 `gpt-5.6-luna` ($0.20 / $1.20).
- 채점에 비싼 쪽을 쓴 이유: 이 앱의 핵심이 일본어 뉘앙스 판정이라서. 채점 1번(3회) 약 $0.02(약 3엔).
- LLM 호출은 `coach/llm.py` 한 곳에만. `LLM_PROVIDER=gemini` 로 되돌릴 수 있게 Gemini 경로도 유지.
- OpenAI 구조화 출력은 strict 모드(모든 필드 required, additionalProperties=false)로 받고, 다시 pydantic 으로 검증.

## 버린 대안
- Gemini 유료 전환: 가능했지만 사용자가 OpenAI 키를 제공.
- 가벼운 모델(`flash-lite`, `luna`)로 채점: 싸지만 뉘앙스 판정 품질 미검증. 추후 같은 평가 세트로 비교할 가치 있음.

## 결과
- 오늘 API 비용 약 $2.4 (실험 2회 + 확인 호출). 크레딧 소진으로 한 번 멈췄다 → 잔액 부족은 재시도 없이 바로 멈추게 처리.
